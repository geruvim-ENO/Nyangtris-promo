# 냥트리스 게임 소개 관리

`promo.json`을 고쳐 main에 올리면 앱 업데이트 없이 반영됩니다.
깃허브 캐시 때문에 보통 5분 안팎이 걸리고, 앱은 켤 때와 30분 이상 지나 다시 돌아올 때 새 설정을 받습니다.

## 전체 켜기 · 끄기

맨 위 `"enabled"`를 `true`(켜기) 또는 `false`(끄기)로 바꿉니다.

## 게임 하나만 끄기

그 게임의 `"enabled"`를 `false`로 바꿉니다.

## 게임 추가

1. 아이콘을 `icons/` 폴더에 넣습니다 (정사각형 PNG, 512×512 권장, 4MB 이하, 파일 이름은 영문 · 숫자).
2. `games` 목록에 아래 항목을 추가합니다. 앞 항목 끝에 쉼표를 넣어야 합니다.

```json
{
  "enabled": true,
  "name": "게임 이름",
  "tagline": "첫째 줄 소개\n둘째 줄 소개",
  "features": ["특징 1", "특징 2", "특징 3"],
  "icon": "icons/파일이름.png",
  "packageId": "com.innoverse.example"
}
```

`packageId`는 구글 플레이 주소의 `id=` 뒤에 있는 값입니다. 스토어에 공개된 게임만 넣습니다.
